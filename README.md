# CGHE Analyzer

CGHE Analyzer calculates a time-resolved hydrogen diffusion coefficient from
carrier-gas hot-extraction measurement signals. It provides an axisymmetric
numerical inverse, a full three-dimensional numerical solver, and an
experimental finite-cylinder analytical inversion.

## Downloads

The [v0.6.1 release](https://github.com/DenisCzeskleba/CGHE-Analyzer/releases/tag/v0.6.1)
provides a portable Windows application and a source archive. Extract the
complete portable folder before opening `CGHE Analyzer.exe`.

The readable source, pinned dependencies, help, and sanitized examples are in
[`Plain Files`](Plain%20Files). The included example result contains the
processed measurement, diffusion result, diagnostics, and saved concentration
fields.

## WeldCraft

CGHE Analyzer is also included in the main WeldCraft suite. WeldCraft is the
primary development version and may receive fixes and improvements before they
are incorporated here. Standalone releases are updated periodically when
meaningful changes have accumulated.

The standalone application uses the theme last selected in WeldCraft and
defaults to the WeldCraft theme for new users.
